ALM 스킬 사용 안내

TC를 올리고, Test Run을 수행하고, 문서를 승인할 때 필요한 절차를 교육 자료와 영상 근거로 확인합니다. VXvue·Bellalun의 제품 사양은 해당 제품 스킬과 함께 살펴봅니다.

ALM 공통 매뉴얼과 SW 검증 교육 자료를 정리했습니다. 링크는 서버의 현재 자료 판을 따릅니다. 이 화면의 자료 목록 표시는 현재 ALM 운영 설정을 검증했다는 뜻이 아닙니다.

이런 일을 도와줍니다

TC 준비와 수정

Excel 신규 Import와 Roundtrip 수정을 구분하고, 필드 매핑·기존 ID 보존·LiveDoc 구성 방법을 확인합니다.

시험과 이슈 처리

Test Run 구성·실행·결과 검토·실패 이슈·재시험·DC와 변경 영향을 업무 순서대로 살펴봅니다.

승인과 산출물 보관

문서 서명과 상태 변경을 구분하고, 보고서·Baseline·Collection·PDF 보관까지 확인합니다.

근거 다시 찾기

가이드의 장, 원본 슬라이드 번호, 영상 시점으로 돌아가 설명의 근거와 확인되지 않은 범위를 살펴봅니다.

Codex와 Claude Code에 설치하기

Python 3을 실행할 수 있는 PC와 QA 서버에 접속할 수 있는 사내망이 필요합니다. ALM 계정·비밀번호·토큰을 이 스킬에 입력하지 않습니다.

  1. 준비 사항을 확인합니다.

    Windows PowerShell에서 py --version을 실행해 Python 3이 있는지 확인합니다. 다른 운영체제에서는 python3 --version을 사용합니다.

  2. 위의 ALM 스킬 ZIP을 받고 압축을 풉니다.

    압축 안의 alm 폴더 전체를 사용합니다. SKILL.md, scripts, server.json을 함께 둡니다.

  3. 사용하는 도구의 사용자 스킬 폴더에 넣습니다.
    사용 도구Windows에서 둘 위치
    Codex%USERPROFILE%\.codex\skills\alm
    Claude Code%USERPROFILE%\.claude\skills\alm

    macOS·Linux에서는 홈 폴더 아래 ~/.codex/skills/alm 또는 ~/.claude/skills/alm을 사용합니다. 같은 이름의 사용자 수정본이 있으면 먼저 보관하고 내용을 비교합니다.

  4. 새 대화에서 첫 질문을 합니다.

    ALM 스킬로 Test Run을 만들고 결과를 확인하는 순서를 근거와 함께 알려줘.

    가이드의 절차와 함께 M220 같은 원본 슬라이드나 영상 시점이 제시되는지 확인합니다. Codex에서는 $alm으로도 부를 수 있습니다.

서버 자료를 읽는지 직접 확인하기

Codex 사용자 폴더에 설치했다면 PowerShell에서 실행합니다. Claude Code만 사용한다면 경로의 .codex를 .claude로 바꿉니다.

py "$env:USERPROFILE\.codex\skills\alm\scripts\knowledge.py" status

metadata_verified: true와 자료 판·가이드 장수 등이 나오면 자료 목록과 본문 파일의 해시 대조가 끝난 것입니다. 실제 ALM에서 시험이나 승인을 실행한 결과는 아닙니다.

이 설치 안내는 로컬 Python을 실행하는 Codex·Claude Code용입니다. Claude Desktop의 일반 채팅에 설치하는 MCP 확장 파일은 제공하지 않습니다. 브라우저의 상세 가이드와 영상은 별도 스킬 설치 없이 사용할 수 있습니다.

VXvue와 Bellalun 스킬을 함께 사용하기

확인할 것담당하는 근거
ALM의 Import·Test Run·승인·이슈 처리 순서ALM 스킬의 공통 교육 자료와 사용 가이드
제품 기능의 Expected·기존 TC·버전별 조건VXvue 또는 Bellalun 스킬이 지정한 사양·매뉴얼·TC
실제 시험의 성공과 실패해당 버전에서 수행한 결과와 캡처·로그 등 증거

예를 들어 “Bellalun의 변경 사양을 제품 스킬로 확인하고, ALM 스킬로 SRS와 TC 연결 및 재시험 준비 절차를 정리해줘”라고 요청할 수 있습니다. 기존 제품 스킬과 연결 설정을 교체할 필요는 없습니다.

로그인된 Edge·Chrome에서 실제 작업하기

구체적인 등록·수정 작업을 요청하면 AI가 현재 로그인된 브라우저에서 대상을 확인하고 작업한 뒤 저장 결과를 다시 읽도록 스킬에 절차를 넣었습니다. 실행 환경에 Computer Use 도구가 연결되어 있어야 합니다.

요청할 수 있는 작업완료할 때 확인할 것
TC 생성·속성·단계 수정대상 ID·기존 값 보존·저장된 내용·중복 여부
SRS와 TC 연결양쪽 ID·관계 방향·Coverage
Test Run 초안 생성이름·Plan Scope·포함 TC·초기 상태
Issue 등록·수정과 자료 첨부발생 버전·본문·담당자·TC 및 증거 연결
Excel Import와 결과 기록Preview·처리 결과·대상 ID·실제 수행 증거
  1. 사용할 브라우저와 프로젝트, 대상 TC·Issue·문서 및 바꿀 값을 알려줍니다.
  2. AI가 현재 서버·프로젝트·상태를 읽고 요청 범위를 확인합니다.
  3. 허용된 작업을 수행한 뒤 같은 ID를 다시 열어 저장값을 확인합니다.
  4. 변경 전후와 저장 결과, 미수행·확인 불가 항목을 보고합니다.

요청 예시: 현재 로그인된 Edge의 ALM에서 지정한 TC 목록으로 Test Run 초안을 만들고, Plan Scope와 포함된 TC ID를 확인해줘.

실제 실행 증거 없이 Passed를 입력하거나 전자서명을 대신하지 않습니다. 전자서명은 사용자가 직접 처리합니다. 이미 요청한 범위의 일반 저장마다 허락을 반복해서 묻지 않으며, 삭제 등 별도 확인이 필요한 행동은 사용하는 컴퓨터 제어 도구의 정책을 따릅니다.

현재는 브라우저 작업 규칙과 스킬 배포를 구현한 상태입니다. 실제 로그인된 ALM에서 등록·수정·저장 성공을 검증한 상태는 아닙니다. 브라우저 연결이나 창·화면 식별이 불확실하면 입력하지 않고 중단합니다. 새 자동화 프로필로 바꾸거나 로그인 정보를 추출하지 않습니다.

이렇게 질문해 보세요

아래 답변 요점은 서버 가이드에서 확인한 사례입니다. 현재 운영 설정과 제품 시험 결과는 별도로 확인합니다.

ALM 스킬로 TC를 Roundtrip 수정할 때 기존 ALM ID를 지워도 되는지 근거와 함께 알려줘.

기존 항목을 갱신하려면 내보낸 ALM ID와 행 구조를 보존합니다. Import 후 같은 ID에 수정이 반영됐는지, 불필요한 새 TC가 생기지 않았는지 확인합니다.

근거: 가이드 10장 · Q8 · M237 · V02

ALM 스킬로 Q19 승인 영상이 최종 Approved 완료까지 보여주는지 확인해줘.

Q19는 승인 절차를 설명하지만 V10의 확인된 화면은 검토 서명과 Reviewed 상태까지입니다. 최종 승인자 처리 전체를 확인한 증거로 사용하지 않습니다.

근거: 가이드 23장과 28장 · Q19 · V10 00:10과 00:30

VXvue AI와 ALM 스킬을 함께 사용해서 변경 사양의 기존 TC를 검토하고, SRS 연결과 재시험 준비 방법을 정리해줘.

제품 스킬로 사양과 기존 TC를 대조한 뒤, ALM 스킬로 추적성·Coverage·새 Test Run 준비 순서를 확인합니다. 자료 조사와 실제 재검증 결과를 구분합니다.

활용 예시: 제품별 사양 조회와 ALM 가이드 11장 및 17장을 함께 사용

자료를 사용할 때 알아둘 점

  • 교육 자료의 작성 시점과 현재 서버 설정은 다를 수 있습니다. 문서 유형·상태 이름·허용 Action·권한은 현재 ALM에서 확인합니다.
  • 영상은 시간별 화면 표본을 대조했습니다. 음성 전체 전사와 표본 사이의 모든 클릭 확인은 포함하지 않았습니다.
  • 서버 자료의 조회 도구는 읽기 전용입니다. 실제 ALM 변경은 구체적인 요청을 받은 브라우저 작업으로 구분하며, 실제 수행 증거 없이 시험 결과를 만들거나 전자서명을 대신하지 않습니다.
  • 서버 자료의 해시가 맞지 않으면 조회를 중단합니다. 오래된 로컬 자료로 바꿔 읽었다고 처리하지 않습니다.

사용이 안 될 때

자료 버튼이 활성화되지 않습니다
사내망 또는 VPN과 QA 서버 연결을 확인하고 “다시 불러오기”를 누릅니다. 실패 중에는 확인되지 않은 자료 링크를 열지 않습니다.
스킬 이름이 보이지 않습니다
압축을 푼 폴더가 alm/alm/SKILL.md처럼 중첩되지 않았는지 확인합니다. 설치 후 새 대화를 시작합니다.
Python 실행을 찾지 못합니다
Python 3 설치와 실행 경로를 확인합니다. 스킬이 실행되지 않아도 브라우저의 상세 가이드는 이용할 수 있습니다.
해시 불일치가 나옵니다
자료 갱신이 끝난 뒤 status를 다시 확인합니다. 계속 실패하면 자료 판과 오류를 운영 담당자에게 전달합니다.
현재 화면과 교육 자료가 다릅니다
현재 문서 유형과 상태를 확인하고 가이드 23장의 자료 차이 목록을 함께 읽습니다. 교육 자료의 오탈자를 실제 상태 이름으로 입력하지 않습니다.
