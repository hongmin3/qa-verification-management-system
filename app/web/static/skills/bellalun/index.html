Bellalun AI 설치·사용 가이드

Bellalun Viewer의 사양서·매뉴얼·기존 TC와 최신 통합 QA 지침을 QA 서버에서 찾아 근거와 함께 답합니다. 개인 PC에 지식파일을 복사할 필요 없이 사내 파트원이 같은 자료 판을 사용합니다.

연결 프로그램의 표시 이름은 VXvue AI입니다. 이 연결에 Bellalun 전용 도구를 함께 제공합니다. Bellalun 질문에는 bellalun_ 도구와 Bellalun QA 지침을 사용합니다.

설치 · 첫 질문 · 업무 예시 · 최신화 · 지원 범위 · 문제 해결

1. 연결과 Skill 설치

Claude Desktop

  1. 이미 VXvue AI 확장을 사용한다면 확장을 껐다 켜고 새 대화를 엽니다. 신규 사용자는 공용 서버 확장(.mcpb)을 직접 받습니다. PC 등록 번호가 있으므로 받은 파일을 다른 사람에게 전달하지 않습니다.
  2. Claude Desktop의 설정 → 확장 프로그램 → 고급 설정 → 확장 프로그램 설치에서 받은 파일을 설치합니다. 자세한 화면 순서는 연결 설치 안내에 있습니다.
  3. Bellalun 서버 Skill ZIP을 받아 사용자 지정(Customize) → Skills → + → 스킬 만들기 → 스킬 업로드에서 등록하고 켭니다.

Claude Code

기존 공용 연결 설치 안내의 PowerShell 명령으로 사용자 범위 연결을 설치합니다. 서버 주소나 키를 수동 복사하지 않습니다. 위 Skill ZIP의 bellalun-server-ai 폴더를 ~/.claude/skills/ 아래에 풀고 Claude Code를 새로 시작합니다.

Codex

기존에 연결한 VXvue AI (QA 서버) 플러그인을 활성화하고 연결을 다시 불러옵니다. 위 ZIP의 bellalun-server-ai 폴더를 사용자 스킬 위치인 ~/.agents/skills/ 아래에 풀고 새 작업에서 $bellalun-server-ai를 호출합니다. 기존 설치가 ~/.codex/skills/를 사용하는 환경은 그 위치를 유지할 수 있습니다. 서버 연결이 아직 없다면 관리자가 제공하는 기존 QA 서버 연결을 먼저 설치해야 합니다. Skill ZIP만으로 서버 연결이 생기지는 않습니다. 공식 Skill 설치 위치 안내도 참고하세요.

기존 로컬 bellalun-ai·bellalun-local-knowledge는 보존됩니다. 서버에서 조사할 때는 bellalun-server-ai를 선택합니다.

2. 첫 질문과 확인할 결과

Bellalun 서버 스킬로 현재 자료 목록과 최신 QA 지침을 확인해줘.
bellalun_get_status와 bellalun_get_workflow를 사용하고 지침은 끝까지 읽어줘.

정상 연결이면 Bellalun 문서 목록·해시·bellalun-으로 시작하는 자료 판과 추출 한계가 확인됩니다. 다음 질문은 같은 판에서 검색하고 원문을 읽습니다. 원문 파일명과 페이지 또는 시트·행을 답에 남겨야 합니다.

3. 업무별 요청 예시

업무복사해서 사용할 질문
사양 확인Crop과 Image Processing의 적용 범위를 사양서·매뉴얼에서 찾아줘. 촬영 UI, Send Preview, 수신 DICOM의 근거를 구분해줘.
기존 TC 검토이 변경사항을 기존 TC가 검출할 수 있는지 Step·Expected로 대조하고, 누락 후보와 근거를 보여줘.
이슈 초안첨부 캡처·로그에서 확인한 Actual과 문서상 Expected를 구분해 이슈 초안을 작성해줘. 조회하지 못한 관련 이슈는 미확인으로 표시해줘.
매뉴얼 대조첨부한 매뉴얼 개정 내용을 관련 사양과 대조해줘. 원문 문구, 한국어 설명, 판단 근거, 수정 제안을 구분해줘.
검증 결과 메일제공한 수행 결과만으로 통합 QA 지침 양식의 메일 초안을 작성해줘. 날짜·횟수·적합 판정은 내가 준 값만 사용해줘.

4. 최신 지침과 자료 동기화

담당자가 공통 Skill과 지식 폴더를 서버에 동기화하면 모든 사용자의 다음 상태·지침 조회에 새 자료 판이 반영됩니다. QA 규칙 변경 때마다 Skill ZIP을 다시 설치할 필요는 없습니다. 진행 중인 조회는 이미 받은 판을 유지하며 서버 재시작 후에는 상태부터 다시 확인합니다.

공통 QA 지침은 통합본 하나를 사용합니다. 서버의 원본 해시와 담당자 원본을 비교해 동기화 여부를 확인합니다. 운영자가 쓰는 동기화 절차는 Bellalun 자료 현황에서 결과를 확인합니다.

담당자 PC의 별도 Bellalun 동기화는 매일 10:10과 로그인 때 실행합니다. 실패하면 15분 간격으로 3회 재시도합니다. 담당자 PC가 로그인되어 있어야 하며, 공통 원본 변경이 서버에 반영되는 시각은 마지막 성공한 동기화를 기준으로 확인합니다.

5. 지원 범위와 확인이 필요한 부분

  • 실제 Viewer 실행·장비 제어·수신 DICOM 검증 결과를 대신 만들지 않습니다. 문서상 Expected와 실제 관찰은 따로 판단합니다.
  • 이 서버의 Bellalun 도구에는 실시간 Redmine 조회·이슈 수정·메일 발송·공통 Skill 수정 기능이 없습니다. 관련 이슈 본문과 로그는 제공한 자료로 검토합니다.
  • DOCX는 문단·표 위치로 인용하며 Word 출력 페이지·변경 추적·메모의 모든 표시를 보장하지 않습니다. PDF 그림·표는 원본 페이지 이미지를 직접 확인합니다.
  • 검색 결과가 없거나 텍스트가 적다는 이유만으로 기능 미지원이나 사양 부재를 확정하지 않습니다.
  • 기존 사내 접속·PC별 등록·회수 정책이 적용됩니다. 외부 인터넷에 제품 자료를 공개하는 서비스가 아닙니다.

6. 연결이 안 될 때

  1. 사내망에서 이 안내와 서버 상태가 열리는지 확인합니다.
  2. 연결을 다시 시작하고 새 대화에서 bellalun_get_status를 요청합니다. 도구가 계속 안 보이면 이 화면의 최신 확장을 다시 받아 설치합니다.
  3. PC 등록이 만료되거나 회수됐다면 각자 설치 파일을 새로 받습니다. 다른 PC의 키나 파일을 복사하지 않습니다.
  4. 자료 누락·해시 불일치·지침 오류는 운영 담당자에게 도구명·오류·자료 판만 전달합니다. 키·설정 파일 전체는 보내지 않습니다.
  5. 서버 조회가 실패한 상태를 자료 확인 완료로 표시하지 않고, 로컬 자료로 바꾸기 전에 조회 대상을 다시 정합니다.
