XIPL 스킬

VXvue와 Bellalun이 함께 참조하는 XIPL User Manual·STUDIO Manual·Revision History를 조회합니다.

공용 조회 안내

XIPL은 기존 VXvue AI 연결의 공용 자료 조회 도구를 사용합니다. 별도 XIPL 설치 ZIP을 제공하는 구성은 아닙니다.

공용 조회 연결 설치 안내

조회 순서

  1. xipl_get_status로 자료 판과 문서 목록을 확인합니다.
  2. 같은 snapshot_id로 검색·원문·PDF 페이지를 조회합니다.
  3. 해당 제품의 사양·라이선스·Expected는 VXvue 또는 Bellalun 스킬로 별도 확인합니다.
예시: XIPL 공용 자료에서 이 기능의 설명과 개정 이력을 찾고, VXvue 적용 사양과 비교해줘.

공용 매뉴얼에 기능이 있다는 사실만으로 제품 지원이나 실제 시험 성공을 판단하지 않습니다.
