XIPL 공용 문서 상세 사용 안내

XIPL User Manual·STUDIO Manual·Revision History를 같은 자료 판에서 찾아보고, VXvue·Bellalun 업무에 필요한 근거를 확인합니다.

연결 준비 · 첫 사용 · 조회 기능 · 업무 예시 · 지원 범위 · 문제 해결

1. 연결 준비

XIPL 공용 조회는 기존 VXvue AI 서버 연결에 포함됩니다. 별도 XIPL ZIP을 설치하거나 인증정보를 복사하는 방식이 아닙니다. 연결 이름이 VXvue AI여도 XIPL 전용 도구로 공용 문서를 읽습니다.

  1. 서버 연결 설치 안내에서 사용 중인 Claude Desktop 또는 CLI에 맞는 설치를 완료합니다.
  2. 이미 연결했다면 도구 목록을 다시 불러오고 xipl_get_status가 있는지 확인합니다.
  3. 아래 첫 질문으로 문서 목록과 조회 가능 여부를 확인합니다. 이 웹페이지가 열리는 것만으로 AI 연결이 준비된 것은 아닙니다.

2. 첫 질문부터 원문 확인까지

XIPL 공용 자료의 현재 상태와 문서 목록을 확인해줘. snapshot_id와 자료의 추출 한계를 알려주고, User Manual과 Revision History에서 내가 질문할 기능을 찾을 준비를 해줘.
  1. AI가 xipl_get_status로 문서 목록·해시·snapshot_id를 확인합니다.
  2. 문서 종류와 기능명을 정해 검색합니다. 매뉴얼 설명과 개정 이력은 각각 확인합니다.
  3. 검색된 문서의 원문을 읽고, 표나 화면이 중요하면 PDF 페이지도 확인합니다.
  4. 같은 작업에서는 같은 snapshot_id를 유지합니다. 새 판이 필요하면 상태 조회부터 다시 시작합니다.
  5. 답변에 문서명·자료 판·본문 위치와 확인하지 못한 범위를 남깁니다.

3. 사용할 수 있는 조회 기능

도구쓰는 때확인할 결과
xipl_get_status작업 시작·자료 갱신 후문서 목록, 해시, snapshot_id, 추출 한계
xipl_search_documents기능명·메시지·설정 설명 찾기관련 문서와 원문 위치. 검색 요약만으로 결론 내리지 않기
xipl_get_document찾은 설명·표·개정 항목을 자세히 읽기같은 판의 원문과 잘림 여부. 잘리면 이어 읽기
xipl_get_document_pagePDF의 화면·표·작은 글자를 확인하기해당 문서의 실제 PDF 페이지 이미지

문서 ID는 상태 조회에서 받은 목록의 값을 사용합니다. 기억한 파일 경로나 다른 제품의 ID를 대신 넣지 않습니다.

4. 업무별 질문 예시

기능 설명과 설정 찾기

XIPL 공용 매뉴얼에서 [기능명]의 사용 조건과 설정 방법을 찾아줘. 원문을 읽고 관련 PDF 표나 화면도 확인해줘. 설명이 없는 부분은 추측하지 말아줘.

개정 이력과 검증 관점 정리

Revision History에서 [버전 또는 기능명]의 변경을 찾고 User Manual의 관련 설명과 비교해줘. 문서에 적힌 변경과 제품에서 추가 확인할 항목을 구분해줘.

VXvue 또는 Bellalun과 함께 검토

XIPL 문서에서 [기능명]을 찾고, [VXvue 또는 Bellalun] 스킬로 해당 제품의 적용 사양과 기존 TC를 확인해줘. 공용 설명·제품 Expected·실제 관찰을 나눠서 정리해줘.

ALM 기록 준비

확인한 XIPL 원문과 제품 사양을 근거로 ALM 스킬과 함께 검증 TC 초안을 정리해줘. 실제 실행하지 않은 항목은 Passed로 기록하지 말아줘.

5. 지원 범위와 결과를 읽는 기준

  • 공용 문서 조회입니다. 매뉴얼에 기능이 있다는 사실만으로 특정 뷰어의 지원·라이선스·실제 동작을 확정하지 않습니다.
  • DOCX는 문단·표 위치로 조회합니다. 렌더링하지 않은 Word 쪽수를 만들거나 PDF 페이지 조회 도구로 DOCX를 열지 않습니다.
  • 변경 추적·메모·이미지 등 추출 한계가 있으면 상태·원문 응답에서 확인하고 필요한 원본을 대조합니다.
  • 문서 조회는 읽기 전용입니다. 제품 시험·설정 변경·ALM 등록은 별도의 구체적인 요청과 실행 확인이 필요합니다.
  • 문서 이름·해시는 읽은 자료를 식별하는 근거입니다. 실제 제품 시험 완료를 증명하지 않습니다.

6. 연결·조회가 안 될 때

XIPL 도구가 안 보임
기존 연결의 최신 설치 안내를 확인하고 연결·도구 목록을 다시 불러옵니다. 별도 키를 공유하거나 인증을 끄지 않습니다.
자료 판을 찾을 수 없음
서버 재시작 또는 보관 범위를 지난 판일 수 있습니다. 상태 조회부터 다시 시작하고 새 판의 문서 ID를 사용합니다.
자료 누락·해시 불일치·추출 오류
정상 판이라고 처리하지 않습니다. 표시된 오류와 문서명을 정리해 자료 수집 상태를 확인합니다.
검색 결과 없음
기능의 영문명·설정명·동의어와 다른 문서 종류로 다시 조회합니다. 결과가 없다는 이유만으로 기능 미지원이라고 판단하지 않습니다.
제품별 Expected가 필요함
VXvue 또는 Bellalun 스킬의 해당 제품 사양을 확인합니다. 공용 문서의 설명만 복사해 제품 사양으로 쓰지 않습니다.
