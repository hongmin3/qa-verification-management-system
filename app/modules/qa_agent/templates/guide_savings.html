사양·이슈 분석 사용법

사용자 지침 프롬프트와 QA 규칙 MD를 기준으로 분석합니다. 결과는 AI 초안이며 QA가 최종 판단합니다.

검증 버전을 먼저 선택하세요

자동 점검과 메일에서 등록된 변경사항 Checklist의 시트를 선택합니다. V1.1.0이 하나면 처음 선택됩니다. 파일이나 시트가 없으면 다른 버전으로 대신하지 않고 확인 필요로 알립니다.

버튼언제 사용하나요?얻는 결과
사양 변경 분석 준비기간 중 바뀐 사양의 검증 범위를 확인할 때관련 이슈·선택한 TC의 검증 범위, 빠진 체크리스트 제안
이슈 변경 분석 준비기간 중 새 이슈나 연구소 설명·조치가 바뀌었을 때사양 원문과의 비교, QA 대응, 수정 확인 방법과 TC 보완점
  1. 기간과 분석 목적을 고릅니다. 대상 준비는 AI를 호출하지 않습니다.
  2. 실제 비교 기준일과 대상 목록을 확인하고 분석할 항목만 선택합니다. 30분이 지났거나 자료·설정이 바뀌면 다시 준비합니다.
  3. 일반 분석은 Sonnet·medium을 사용합니다. 기존 분석과 근거가 같으면 AI 없이 원래 결과를 보여줍니다. 선택한 한 항목에만 Opus 재검토를 요청할 수 있습니다.

시작일 이전 기록이 없으면 실제 비교 기준이 선택한 시작일보다 늦을 수 있습니다. 기록이 없는 기간을 확인한 것으로 표시하지 않습니다.

자동 점검과 메일

자동 분석·메일 사용과 현재 검증 진행 중을 모두 켜면 매 업무일, 자동 분석·메일만 켜면 그 주 첫 업무일에 두 분석을 함께 수행합니다. 공휴일에는 실행하지 않습니다.

기존 결과를 먼저 재사용하고 새 호출은 화면의 공통 예산을 따릅니다. 횟수 제한은 Claude 계정의 5시간 사용률 제한을 뜻하지 않습니다. 한도 뒤 별도 자동 재실행은 없으며 남은 대상은 다음 예정 실행 또는 수동 선택에서 이어 갑니다.

메일 한 통에 검증 버전·실제 비교 기간, 사양/이슈 분석 건수, 재사용·미분석·오류와 결과 링크를 담습니다. 상세 근거는 웹에서 확인하며 메일 작성용 AI 호출은 없습니다. 이슈 결과는 최초 작성자별로 묶고 각 작성자의 최신 업데이트부터 보여줍니다.

분석결과를 찾고 처리하기

분석결과에서 이슈/사양 종류, 최초 작성자, 번호, 내용, 판정, 처리 상태를 검색합니다. 기본은 이슈 업데이트 최신순이며 작성자·이슈 번호·분석 시각으로도 정렬할 수 있습니다. 이슈 업데이트 날짜와 시간은 한국 시간으로 표시합니다. 기간 필터는 원래 분석 시각 기준입니다. 새 실행에서 재사용한 결과는 그 실행의 결과 링크로 확인합니다.

상세 화면은 판단과 할 일, 근거 자료, 분석 기록·처리 상태로 나뉩니다. AI 판정은 사양과 다름·검토 필요·근거 부족·참고·문제 없음이며 화면에서 각 기준을 확인할 수 있습니다.

조치가 끝났거나 더 할 일이 없으면 확인 완료로 기록하세요. 이 상태는 QA의 업무 처리 기록이며 이슈 종료나 실제 장비 검증 PASS를 뜻하지 않습니다. 새로운 분석 결과는 다시 미처리로 시작합니다.
