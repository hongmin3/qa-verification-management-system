QA 홈

Claude에서 VXvue AI 사용하기

파트원 PC의 Claude가 QA 서버의 사양·매뉴얼·TC·최신 QA 지침과 Polarion 자료를 읽어 답합니다. 설치 파일을 받아 설치하면 QA 서버에 자동으로 연결됩니다. 서버 주소·토큰·Polarion 계정은 입력하지 않습니다.

Claude Desktop (일반 채팅·Cowork)

  1. VXvue AI 확장 다운로드 — 받을 때마다 이 PC를 한 번 등록할 수 있는 번호가 새로 들어갑니다. 받은 파일을 다른 사람에게 전달하지 말고 각자 이 화면에서 받습니다.
  2. 받은 vxvue-ai.mcpb를 두 번 클릭하거나, Claude Desktop의 Settings → Extensions → Advanced settings → Install Extension…에서 선택합니다. Claude가 설치 확인 창을 띄우면 Install을 누릅니다. 입력할 값은 없습니다.
  3. 새 대화에서 VXvue 질문을 합니다. 처음 도구를 쓸 때 Claude가 VXvue AI 도구 사용 허용을 물으면 허용합니다(읽기 전용 도구입니다).

Python·Node.js·SSH 설치나 설정 파일 편집은 필요 없습니다. 확장은 Claude Desktop에 들어 있는 Node.js로 실행됩니다. 앱을 다시 시작해도 이 PC에 저장된 연결 키로 다시 연결됩니다.

VXvue AI Skill (선택)

확장만 설치해도 Claude가 연결 지침에 따라 최신 Skill·QA 규칙을 서버에서 읽습니다. 질문하지 않아도 VXvue 작업 순서를 먼저 떠올리게 하려면 VXvue AI Skill ZIP을 받아 Customize → Skills → + Create skill → Upload a skill에서 올리고 켭니다. Team·Enterprise에서는 담당자가 올린 Skill을 … → Share로 공유할 수 있고, 공유받은 사용자는 소유자가 수정한 Skill을 다음 사용 때 받습니다.

Claude Code CLI

PowerShell 창에서 아래 한 줄을 실행합니다. 이 PC를 등록하고, Claude Code 사용자 범위에 vxvue-ai 연결과 Skill을 등록합니다.

irm {{SERVER}}/vxvue-desktop/claude-code/install.ps1 | iex

이미 Desktop 확장으로 등록한 PC라면 같은 연결 키를 다시 씁니다. 실행 후 Claude Code를 새로 시작하고, 처음 도구를 쓸 때 사용 허용을 물으면 허용합니다. 같은 이름의 다른 Skill이 이미 있으면 덮어쓰지 않고 알립니다.

질문 예시

  • VXvue AI로 최신 지침을 읽고 VP-1234의 사양·이슈와 연결된 사양 및 TC를 분석해줘.
  • 이 Polarion 필터에 맞는 항목을 모든 페이지에서 수집하고, 각 항목의 본문·댓글·관련 사양을 확인해 검증 범위를 분석해줘. [필터 입력]
  • Ecoray Generator의 Ready 상태 전환을 사양과 기존 TC로 대조해줘.

필터는 Polarion 문법 그대로 입력합니다. 수집한 목록은 분석 완료가 아닙니다. Claude에게 필요한 항목의 본문·댓글·연결 사양까지 읽도록 요청하세요. 첨부 목록은 제공하지만 Polarion 첨부 본문은 자동 수집하지 않습니다.

자동 연결과 접근 범위

  • 설치 파일에는 QA 서버 주소와 한 번만 쓰이는 등록 번호(유효 7일)만 들어 있습니다. 처음 실행할 때 이 번호를 이 PC 전용 연결 키로 바꿔 사용자 폴더의 .vxvue-ai에 저장합니다.
  • 등록·연결은 사내망(사설 IP 대역)에서만 됩니다. 서버는 연결 키를 해시로만 저장하고, PC 이름·사용자 이름·접속 주소·마지막 사용 시각을 기록합니다. 관리자는 PC별로 연결을 취소할 수 있습니다. 90일 동안 쓰지 않은 연결 키는 만료됩니다.
  • Polarion 계정은 QA 서버에만 있고 PC로 보내지 않습니다. 이 연결은 Polarion 수정·이슈 등록·원본 TC 변경이나 서버 AI 호출을 하지 않습니다.

자료와 지침 업데이트

바뀐 것반영 방법
서버 문서·QA 규칙·서버 Skill 지침다음 상태 조회에서 자동 반영. 재설치 필요 없음. 대화 도중에는 시작할 때 받은 지식 판을 유지하므로 최신으로 다시 확인하려면 상태를 새로 조회해 달라고 요청합니다.
연결 확장 자체(Desktop)이 화면에서 새 파일을 받아 설치. 사내 배포 확장은 자동 교체되지 않습니다. 오래된 확장으로 연결하면 Claude가 새 설치 파일을 안내합니다.
Claude Code 연결·Skill위 PowerShell 명령을 다시 실행
업로드한 Skill ZIP새 ZIP을 다시 올리거나, 공유받은 Skill이면 소유자 수정이 다음 사용 때 반영

공식 안내: Skill 업로드·공유·업데이트 · Desktop 확장 설치 · Claude Code MCP

연결이 안 될 때

Claude가 VXvue AI 연결 실패 [원인]으로 시작하는 안내를 보여 줍니다. 원인별 할 일은 다음과 같습니다.

원인할 일
ECONNREFUSED, serverQA 서버 프로그램이 멈췄을 수 있습니다. 이 화면이 브라우저에서 열리는지 확인하고, 안 열리면 QA 서버 관리자에게 알립니다.
ETIMEDOUT, ENOTFOUND, unreachable, timeout사내망 또는 VPN 연결을 확인하고 다시 질문합니다. 연결되면 자동으로 이어집니다.
network_not_allowed사내망 밖 주소에서 접속했습니다. 사내망·VPN에서 다시 시도합니다.
ticket_used, ticket_expired, ticket_unknown, needs_reinstall설치 파일의 등록 번호를 쓸 수 없습니다. 이 화면에서 설치 파일을 새로 받아 설치합니다.
device_revoked, device_expired이 PC의 연결이 취소됐거나 오래 쓰지 않아 만료됐습니다. 새로 받아 설치하고, 취소된 경우에는 관리자에게 먼저 확인합니다.
  • 확장이 안 보이면 앱을 다시 시작하고 조직의 확장 허용 여부를 확인합니다.
  • API 오류와 0건은 다릅니다. 오류가 나오면 필터·권한·서버 상태를 확인한 뒤 재조회합니다.
  • 연결 키·등록 번호를 채팅에 붙이지 않습니다.

이전 판(1.0.0) 확장을 서버 주소·팀 토큰 입력으로 설치한 PC는 지금도 연결됩니다. 새 판을 설치하면 입력 없이 연결되고, 이전 판은 Settings → Extensions에서 제거할 수 있습니다.

검색어와 조회 결과는 서버와 사용자의 Claude 대화로 전달됩니다. 회사의 자료 처리 정책에 맞는 계정으로 사용하세요.
