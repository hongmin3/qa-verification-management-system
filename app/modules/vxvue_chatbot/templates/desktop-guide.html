Claude Desktop 설치 (일반 채팅·Cowork)

  1. VXvue AI 확장 다운로드를 누릅니다. 받을 때마다 이 PC를 한 번 등록할 수 있는 번호(7일 유효)가 새로 들어갑니다. 받은 파일은 다른 사람에게 전달하지 말고 각자 이 화면에서 받습니다.
  2. Claude Desktop에서 설정(Settings) → 확장 프로그램(Extensions) → 고급 설정(Advanced settings) → 확장 프로그램 설치…(Install Extension…)를 누르고 받은 vxvue-ai.mcpb를 선택합니다. 확장 프로그램 화면에 파일을 끌어다 놓아도 됩니다.
  3. 설치 확인 창에서 설치(Install)를 누릅니다. 입력할 값은 없습니다.
  4. 새 대화에서 VXvue 질문을 합니다. 처음 도구를 쓸 때 Claude가 VXvue AI 도구 사용 허용을 물으면 허용합니다(읽기 전용 도구입니다).

Python·Node.js·SSH 설치나 설정 파일 편집은 필요 없습니다. 확장은 Claude Desktop에 들어 있는 Node.js로 실행됩니다. 앱을 다시 시작해도 이 PC에 저장된 연결 키로 다시 연결됩니다.

파트원이 알아 둘 점

질문을 잘하는 법

  • VP 번호, 기능 이름, 모델 이름(예: Ecoray), 버전처럼 찾을 단서를 질문에 넣습니다.
  • 필터는 Polarion 문법 그대로 붙여 넣고 "필터를 바꾸지 말고 모든 페이지를 수집해줘"라고 씁니다.
  • "수집만" 할지 "본문·댓글·관련 사양까지 분석"할지 분명히 말합니다. 목록 수집은 분석 완료가 아닙니다.
  • Issue 초안이 필요하면 "[Precondition]/[Step]/[Expected Result]/[Actual Result]/[Log, Data] 형식으로"라고 요청합니다.

답을 읽는 법

  • 근거(문서명·쪽·시트·행·VP 번호)가 없는 주장은 받아들이지 말고 근거를 다시 요청합니다.
  • "검색되지 않음"은 "지원 안 함"이 아닙니다. 읽을 수 있는 텍스트에서 못 찾았다는 뜻입니다.
  • PDF 표·이미지·취소선은 텍스트로 확정할 수 없습니다. 답에 "원본 확인 필요"가 있으면 원본을 직접 봅니다.
  • Claude는 Pass/Fail이나 실제 실행 결과를 만들지 않습니다. 판정은 사람이 합니다.

할 수 없는 것

  • Polarion·Redmine에 쓰기, 원본 사양서·TC 수정, 메일 발송
  • Polarion 첨부 파일(이미지·로그·영상) 본문 읽기. 첨부 목록만 보입니다.
  • 내 PC의 로컬 파일 검색. 서버에 올라간 자료만 읽습니다.

  • 설치 파일에는 서버 주소와 한 번만 쓰는 등록 번호만 들어 있습니다. 처음 실행할 때 이 PC 전용 연결 키로 바꿔 사용자 폴더의 .vxvue-ai에 저장합니다.
  • 등록·연결은 사내망(사설 IP 대역)에서만 됩니다. 서버는 연결 키를 해시로만 저장하고 PC 이름·사용자 이름·접속 주소·마지막 사용 시각을 기록합니다. 관리자는 PC별로 연결을 취소할 수 있고, 90일 동안 쓰지 않은 키는 만료됩니다.
  • Polarion 계정은 QA 서버에만 있고 PC로 보내지 않습니다. 검색어와 조회 결과는 사용자의 Claude 대화로 전달되므로 회사 자료 처리 정책에 맞는 계정으로 사용합니다.

매뉴얼 검토 공통 도구

매뉴얼 검토 자료 준비에서 등록된 문서를 선택하거나 새 DOCX·PDF를 올립니다. DOCX의 쪽수를 확인하려면 Word에서 저장한 변경내용 표시 PDF와 최종본 PDF를 함께 올릴 수 있습니다.

  1. 화면에 나온 자료 ID를 VXvue AI 대화에 전달합니다.
  2. AI가 공통 도구로 전체 본문·변경추적·기존 메모·그림을 읽고 사양과 대조합니다.
  3. 보고서를 요청하면 원본에서 현재 문구를 그대로 채운 HTML·Excel 파일을 받습니다. 설명과 원문 인용은 구분되며 문단 번호와 PDF 쪽수도 따로 표시합니다.

기존 확장은 재설치할 필요 없이 서버에서 새 도구 목록을 받습니다. 이미 열린 대화에서 새 도구가 보이지 않으면 연결을 껐다 켜거나 새 대화를 시작하세요. 원본·제품 DB·이슈는 바꾸지 않으며, 생성 보고서는 별도 작업 폴더에 저장합니다.

연결이 안 될 때

Claude가 VXvue AI 연결 실패 [원인]으로 시작하는 안내를 보여 줍니다. 원인별 할 일은 다음과 같습니다.

원인할 일
ECONNREFUSED, serverQA 서버 프로그램이 멈췄을 수 있습니다. 이 화면이 브라우저에서 열리는지 확인하고, 안 열리면 QA 서버 관리자에게 알립니다.
ETIMEDOUT, ENOTFOUND, unreachable, timeout사내망 또는 VPN 연결을 확인하고 다시 질문합니다. 연결되면 자동으로 이어집니다.
network_not_allowed사내망 밖 주소에서 접속했습니다. 사내망·VPN에서 다시 시도합니다.
ticket_used, ticket_expired, ticket_unknown, needs_reinstall설치 파일의 등록 번호를 쓸 수 없습니다. 이 화면에서 설치 파일을 새로 받아 설치합니다.
device_revoked, device_expired이 PC의 연결이 취소됐거나 오래 쓰지 않아 만료됐습니다. 새로 받아 설치하고, 취소된 경우에는 관리자에게 먼저 확인합니다.
  • 확장 목록에 "실패"가 보이면 확장 프로그램(Extensions) 화면에서 끄고 다시 켜거나 앱을 다시 시작합니다. 그래도 안 되면 사용자 폴더의 .vxvue-ai\bridge.log(연결 단계 기록, 키 미포함)를 관리자에게 보냅니다.
  • API 오류와 0건은 다릅니다. 오류가 나오면 필터·권한·서버 상태를 확인한 뒤 재조회합니다.

이전 판(1.0.0) 확장을 서버 주소·팀 토큰 입력으로 설치한 PC는 지금도 연결됩니다. 새 판을 설치하면 입력 없이 연결되고, 이전 판은 설정(Settings) → 확장 프로그램(Extensions)에서 제거할 수 있습니다.
