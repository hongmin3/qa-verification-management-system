QA 홈

Claude Desktop에서 VXvue AI 사용하기

파트원 PC의 Claude가 서버의 사양·매뉴얼·TC·최신 QA 지침과 Polarion 자료를 읽어 답합니다. 일반 채팅과 Cowork에서 사용할 확장 패키지를 제공합니다.

  1. VXvue AI 확장 다운로드
  2. Claude Desktop의 Settings → Extensions → Advanced settings → Install Extension…에서 받은 vxvue-ai.mcpb를 선택합니다.
  3. 서버 주소에는 현재 QA 서버 주소를, 팀 접근 토큰에는 관리자가 별도로 전달한 값을 입력합니다. Polarion 비밀번호나 토큰을 입력하지 않습니다.
  4. 앱을 다시 연결하고 새 대화에서 연결된 도구에 VXvue AI가 표시되는지 확인합니다. 조직이 확장을 제한한다면 관리자에게 허용을 요청합니다.

VXvue AI Skill 등록과 팀 공유

VXvue AI Skill ZIP 다운로드 후 Customize → Skills → + Create skill → Upload a skill에서 업로드하고 켭니다. 확장은 서버 연결을, Skill은 최신 지침을 읽고 분석하는 순서를 제공합니다.

Team·Enterprise에서는 담당자가 업로드한 Skill의 … → Share로 파트원에게 공유할 수 있습니다. 공유받은 사용자는 한 번 켜면 이후 소유자가 수정한 Skill을 다음 사용 때 받습니다. 조직 전체 배포는 관리자가 Organization settings → Plugins & skills에서 할 수 있습니다. 각 PC의 연결 확장과 팀 토큰 설정은 별도로 필요합니다.

질문 예시

  • VXvue AI로 최신 지침을 읽고 VP-1234의 사양·이슈와 연결된 사양 및 TC를 분석해줘.
  • 이 Polarion 필터에 맞는 항목을 모든 페이지에서 수집하고, 각 항목의 본문·댓글·관련 사양을 확인해 검증 범위를 분석해줘. [필터 입력]
  • Ecoray Generator의 Ready 상태 전환을 사양과 기존 TC로 대조해줘.

필터는 Polarion 문법 그대로 입력합니다. 수집한 목록은 분석 완료가 아닙니다. Claude에게 필요한 항목의 본문·댓글·연결 사양까지 읽도록 요청하세요. 첨부 목록은 제공하지만 Polarion 첨부 본문은 자동 수집하지 않습니다.

자료와 지침 업데이트

서버 지식 업로드가 완료되면 다음 상태 조회에서 최신 자료·QA 규칙·서버 Skill 지침을 읽습니다. 대화 도중에는 시작할 때 받은 지식 판을 유지합니다. 최신 자료로 다시 확인하려면 상태를 새로 조회해 달라고 요청합니다.

사내 배포 .mcpb 파일은 자동 교체되지 않습니다. 연결 확장 자체를 변경했을 때만 새 파일을 설치하고 앱 연결을 다시 시작하세요. 서버의 문서·규칙·작업 지침 변경에는 재설치가 필요 없습니다. 실제 Chat·Cowork 사용은 앱 버전과 조직 정책에 따라 확인해야 합니다.

공식 안내: Skill 업로드·공유·업데이트 · Desktop 확장 설치

연결이 안 될 때

  • PC에서 QA 서버 화면이 열리는지 확인합니다. 사내망 또는 VPN 연결이 필요합니다.
  • 인증 오류이면 서버 주소와 팀 토큰을 확인합니다. 토큰을 채팅에 붙이지 않습니다.
  • 확장이 안 보이면 앱을 다시 시작하고 조직의 확장 허용 여부를 확인합니다.
  • API 오류와 0건은 다릅니다. 오류가 나오면 필터·권한·서버 상태를 확인한 뒤 재조회합니다.

검색어와 조회 결과는 서버와 사용자의 Claude 대화로 전달됩니다. 회사의 자료 처리 정책에 맞는 계정으로 사용하세요. 이 연결은 Polarion 수정·이슈 등록·원본 TC 변경이나 서버 AI 호출을 수행하지 않습니다.
