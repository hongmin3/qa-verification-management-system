질문하고 자료를 함께 확인하기

사양·매뉴얼 질문, TC 검토, Generator 분석, Issue·메일 초안을 자연스러운 문장으로 요청하세요. 모델·버전·환경과 관찰한 현상을 함께 적으면 적용 조건을 더 정확히 비교할 수 있습니다.

  1. 새 대화를 만들거나 왼쪽에서 이전 대화를 선택합니다.
  2. 질문 한 번에 최대 10개 파일을 첨부합니다. 이전 메시지의 첨부도 후속 질문에서 사용할 수 있습니다.
  3. 답변이 나오는 자리에 진행 카드가 보입니다. 자료 검색, 원문 확인, 답변 작성처럼 지금 단계와 경과 시간을 확인합니다. 원문 인용과 조회한 자료 목록으로 근거를 열어 볼 수 있습니다.
  4. 답변을 복사하거나 Markdown 파일로 내려받습니다. 중지 버튼은 진행 카드 안에 있으며 현재 요청의 답변 생성을 멈춥니다.

답변의 근거는 VP 번호(예: VP-656)와 문서 이름·쪽으로 표시합니다. 사양서의 Status가 draft여도 답변에 단서로 붙이지 않으며, 물어보면 값만 알려 줍니다.

대화 이력

대화는 서버에 저장하고 이 브라우저에서 다시 볼 수 있습니다. 첫 답변이 끝나면 AI가 대화 내용에 맞는 제목을 붙입니다. 제목을 직접 바꾸면 그 뒤로는 AI가 바꾸지 않습니다. 제목 변경과 삭제는 대화 목록에서 합니다. 로그인 없는 첫 버전이므로 쿠키를 지우거나 다른 브라우저를 사용하면 이전 대화를 자동으로 가져오지 못합니다. 다른 사람에게 대화를 공유하는 기능은 없습니다.

지식과 지침

서버에 등록된 VXvue 사양·매뉴얼·TC와 최신 지침 프롬프트·QA 규칙 MD를 읽습니다. PC의 지식 폴더는 매일 08:00 KST에 업로드하며 실패하면 15분마다 다시 시도합니다. PC가 꺼져 있는 동안에는 마지막 정상 업로드본을 사용하고, 다시 켜지면 미완료 동기화를 이어 합니다. 03:30 사양서 동기화로 새 자료가 등록되면 다음 질문에 반영합니다.

읽지 못한 문서나 이미지·표는 답변에 제한으로 표시합니다. 검색 결과가 없다고 미지원이나 사양 없음으로 확정하지 않습니다. 원본 TC 수정·이슈 등록·메일 발송은 수행하지 않습니다.

상단의 Claude 사용량

화면 위쪽에 "5시간"과 "주간" 두 칸이 사용한 비율과 초기화 시각을 보여 줍니다(예: 5시간 37% · 19:19 초기화). 칸에 마우스를 올리면 남은 비율과 측정 시각이 보입니다. 남은 비율이 20% 아래면 주황, 0%면 빨강으로 바뀝니다. 값은 화면을 열 때, 답변이 끝날 때, 화면이 보이는 동안 5분마다 새로 읽습니다.

이 사용량은 서버 Claude 계정 하나의 사용률입니다. 일일 점검과 챗봇이 같은 계정을 나눠 쓰므로 내가 쓰지 않아도 올라갈 수 있습니다. 값을 읽지 못하면 "사용량 알 수 없음"으로 표시합니다.

지식 상태 펼쳐 보기

대화 위쪽의 지식 상태 줄에는 읽는 문서 수와 마지막 정상 동기화 시각이 한 줄로 보입니다. 줄을 누르면 펼쳐지고, 다시 누르면 접힙니다. 접고 펼친 상태는 이 브라우저가 기억합니다.

펼치면 매뉴얼별 상태와 마지막 업데이트 일시, 사양서 자동 업데이트의 마지막 성공 시각, 로컬 Skill의 적용 버전과 서버가 마지막으로 동기화받은 일시가 나옵니다. 제외된 매뉴얼은 접힌 줄에서는 빠지고 펼친 목록에 "제외"와 사유로 보입니다. 지식 동기화에 문제가 있을 때만 마지막 시도와 다음 재시도, 읽지 못한 문서가 더해집니다. PC에 더 새 Skill을 설치했어도 다음 08:00 동기화가 끝나야 이 화면에 반영됩니다.

첨부와 제한

PDF, DOCX, XLSX, MD, TXT, CSV, TSV, JSON, XML, LOG, PNG, JPG, JPEG, WEBP를 지원합니다. 기본 파일당 50MiB, 전체 요청 200MiB입니다. 파싱할 수 없는 파일은 원본 확인을 요청합니다. 글은 외부 AI 전송 전에 민감한 값의 마스킹을 적용합니다. 이미지와 PDF 페이지는 Claude에 이미지로 전달되므로 개인정보를 가린 자료를 첨부하세요. AI 사용량 한도나 인증 문제가 생기면 서버 연결 상태를 확인하거나 한도가 풀린 뒤 다시 요청하세요.

로컬 Skill 최신화

PC의 활성 로컬 Skill에서 지침과 참조 MD를 자동으로 읽어 기존 지식폴더에 [Skill 지침] VXvue.md를 생성합니다. 매일 08:00 동기화 후 다음 질문에 반영됩니다. 이 자동 생성 파일은 직접 편집하지 않고 로컬 Skill을 수정합니다.

QA 규칙 MD·프롬프트 TXT·사양·TC·매뉴얼은 기존 지식폴더에서 계속 관리합니다. 검색 도구와 실행 코드는 별도 검증 후 배포합니다. 화면에 적용 Skill 버전과 도구 갱신 검토 필요 여부가 표시됩니다.

사용량을 줄이는 동작

Opus와 medium 설정을 유지하며 여러 자료를 묶어 조회하고 반복 문서 목록을 줄입니다. 최신 지침과 QA 규칙 전문, 대화 이력과 원문 근거는 유지합니다. 필요한 결과를 먼저 답하고 요청하신 표·TC·초안은 완성합니다.

한 번의 요청이 최대 진행 횟수(기본 24회)에 도달하면 이유를 표시합니다. 질문을 나눠 이어 요청할 수 있습니다. 서버는 캐시 읽기·쓰기와 새 입력·출력 토큰을 구분해서 기록합니다. CLI 비용 추정치는 실제 청구액이나 구독 잔여 사용량과 다릅니다.
