# VXvue 서버형 Skill과 QA 규칙 관리

QA 담당자가 편집하는 업무 지침은 지식폴더의 `[QA 작성 규칙] VXvue TC 설계 및 자체검토 가이드.md` 한 파일이다. 운영 지침과 상세 QA 규칙을 함께 담는다. 개정 번호를 바꿀 때 제품 설정이나 연결 Skill을 다시 등록할 필요가 없다.

| 대상 | 관리 방법 |
|---|---|
| QA 업무 규칙 | 통합 MD의 운영 지침·상세 규칙을 수정하고 기존 지식 동기화 실행 |
| 연결 방법 | `vxvue-server-ai@vxvue-server-local`의 `vxvue-ai` Skill |
| 자동 생성 연결 지침 | `[Skill 지침] VXvue.md`, 직접 편집하지 않음 |
| 서버 사본·질문별 원본 판 | 동기화와 질문 준비가 자동 관리 |
| 구형 로컬 직접 조회·TXT | VXvue 운영 입력에서 제외, 복구본은 지식폴더 밖에 보관 |

통합 MD는 `<!-- qa-rules-format: unified-v1 -->`, `<!-- qa-rules:operations -->`, `<!-- qa-rules:details -->` 구역 표시를 유지한다. 운영 지침과 상세 규칙에는 각각 본문이 필요하다. 내용이 다른 통합 MD가 동시에 있거나 원본 해시가 맞지 않으면 AI 호출 전에 중단한다.

기존 지식 동기화와 실패 재시도 일정은 유지한다. PC가 꺼져 있으면 마지막 서버 사본을 쓴다. 새 요청은 갱신한 원문을 읽고 진행 중인 요청은 준비된 원본 판을 끝까지 사용한다.

서버 연결의 `get_status`와 `get_workflow(snapshot_id, offset, limit)` 계약은 유지한다. 기존 연결에서도 최신 원문을 끝까지 이어 읽는다. 자동 QA는 같은 통합 MD의 운영 지침과 업무별 상세 절을 전달하며, 절 번호 대신 제목과 Skill 의미로 찾는다.

전환할 때 읽기 코드를 먼저 배포한 뒤 통합 MD와 서버형 연결 지침을 동기화한다. 기존 두 원문과 자동 생성 지침은 지식폴더 밖에 백업한다. 구형 파일은 서버 운영 목록에서 제외하되 기존 질문의 원본 판은 보존한다. 다른 제품과 사양서·TC·매뉴얼은 교체하지 않는다.
