# 로컬 VXvue Skill 지침 동기화 계획

기존 지식폴더를 관리 원본으로 유지한다. QA 규칙 MD와 프롬프트 TXT는 그 폴더의 최신 개정본을 읽는다. Skill 지침은 로컬 설치본에서 자동 내보내 같은 지식 업로드로 보낸다.

| 순서 | 작업 | 확인 |
|---|---|---|
| 1 | 실제 동기화 자산 목록에서 규칙을 읽는다 | 문서 DB에 규칙 등록 없이 업로드·확정·챗봇 조회 |
| 2 | Skill 지침 전용 자산 종류와 설정을 추가한다 | 일반 QA 규칙과 구분, 기존 제품 수집 회귀 확인 |
| 3 | 활성 플러그인의 최신 설치 캐시에서 SKILL.md·참조 MD를 자동 내보낸다 | 개정·내용 변경, 불완전 설치·경로 이탈·출처 누락 처리 |
| 4 | 실행 코드·MCP 설정의 해시를 기록한다 | 코드 내용과 자격증명이 문서에 포함되지 않음 |
| 5 | 서버에서 동기화한 Skill을 읽고 적용 버전을 표시한다 | 참조 MD 갱신, 기존 규칙 전문 보존, 도구 변경 검토 상태 |
| 6 | PC 예약 실행본과 운영 배포를 연결한다 | 진행 중 분석 완료 후 서버·PC 코드 반영, 예약 실행본 갱신 |

매일 08:00 KST 지식 업로드와 실패 시 15분 재시도에 포함한다. Skill만 바꾼 날도 다음 정상 동기화 후 적용한다. 같은 날 즉시 반영하려면 Knowledge 지식 동기화를 실행한다.

새 자산 종류를 서버가 받도록 배포한 뒤 PC의 예약 실행본을 갱신한다. 그 전에는 이미 설치한 08:00 예약으로 기존 지식문서 동기화를 유지한다. 도구 코드 변경은 별도의 검토·테스트·배포를 거친다.

설치 캐시가 여러 개면 설정된 플러그인의 숫자 버전이 가장 높은 완성된 설치 폴더를 대상으로 확인한다. 더 높은 버전의 불완전 캐시가 있으면 동기화를 실패로 기록하고 이전 서버 문서를 유지한다. 플러그인이 꺼져 있거나 출처를 읽을 수 없을 때도 오류를 알린다.

내보낸 `[Skill 지침] VXvue.md`는 자동 생성 파일이다. 사람이 수정하는 곳은 기존 QA 규칙·프롬프트·지식문서와 로컬 Skill 원본이다. 서버 사본·검색 색인·질문별 근거 판은 자동 관리한다.
