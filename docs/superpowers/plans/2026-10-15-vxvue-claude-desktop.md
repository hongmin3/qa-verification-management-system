# Claude Desktop 공용 VXvue 연결 구현 계획

**Goal:** Chat과 Cowork에서 서버 원본과 최신 QA 지침을 공동 조회한다.

**Spec:** `specs/vxvue-chatbot.md` REQ-VXVUECHATBOT-011·012.

**Architecture:** 핵심 앱의 기존 Corpus·KnowledgeTools·지식 판 생성기를 재사용한다. Node.js 확장은 표준 입출력 MCP를 인증된 서버 요청으로 전달한다. 외부 공개 URL이나 추가 서비스를 만들지 않으며 파트원에게 SSH 설정을 요구하지 않는다.

## 영향 확인

- 소비자는 Claude Desktop 확장, 기존 챗봇, 배포 스크립트, 지식 업로드 처리다.
- 기존 챗봇 도구는 변경하지 않고 외부 연결에서 허용된 읽기 도구만 선택한다.
- 새 토큰 파일은 없을 때 닫히며 기존 설정 파일과 사용자의 설치 설정을 덮지 않는다.
- 서버 원본과 추출본은 분리하고 manifest의 원본 해시를 확인한다.
- 지식 판과 캐시는 `data/vxvue_desktop/`에 두며 Git에서 제외한다.
- 서버 문서·규칙 갱신과 확장 바이너리 교체를 구분한다. 문서 부재·손상은 차단하고 구버전으로 숨기지 않는다.

## 실행 순서

- [x] 인증·최신 지침·페이지 근거·변경 반영·경로 보호의 실패 테스트를 작성하고 실행한다.
- [x] manifest 어댑터와 핵심 앱 연결 경로를 구현한다.
- [x] Node.js 전달기와 MCPB manifest, 패키지 생성·토큰 초기화 도구를 구현한다.
- [x] 서버 연결과 실제 전달기로 초기화·검색·원문·오류를 실행한다. 실제 Claude 앱 검증은 별도 표시한다.
- [x] 사용법 화면·문서 지도·변경 이력·진행 기록을 갱신한다.
- [x] 관련 회귀·전체 검사·준비 검사·diff를 확인한다. 전체 129개 파일의 분리 실행에서 1,638개 통과·8개 건너뜀이다.
- 관련 변경의 저장 경로는 `codex/vxvue-claude-desktop` 브랜치다. 기존 작업 폴더를 바꾸지 않고 커밋·푸시한다.

## 검토할 실패 경계

인증 부재·틀린 토큰, 교차 출처, 자료 해시 변경·삭제·링크 이탈, 같은 개정의 다른 QA 규칙, 지침 이어 읽기·판 변경, 네트워크 실패·리다이렉트, JSON이 아닌 응답과 한글 입출력을 확인한다.

## 구현 중 확인한 결정

- 사용자 추가 범위인 Polarion VP·필터 조회는 기존 GET 전용 클라이언트를 사용한다. 데이터 수집과 AI 분석을 분리한다.
- 실제 API 단일 항목 조회는 페이지 인수를 받지 않는다. 목록·댓글·첨부·연결 목록에만 페이지 인수를 보낸다.
- 관계가 링크만 반환되는 실제 응답을 확인해 `section=links`를 더했다.
- 민감값 보호는 전체 응답에 먼저 적용하고 그 뒤 글자를 나눈다. 나눈 조각을 다시 바꾸지 않아 JSON과 이어 읽기 위치를 보존한다.
- 독립 검토의 Skill 누락 지적을 반영해 서버 Skill이 없으면 연결을 미준비 상태로 처리한다.
- 운영과 Git의 차이는 최신 `origin/master`를 병합해 확인했다. 다른 세션의 서버 설정은 배포하지 않는다.
