# 매뉴얼 검토 기준과 공통 보고서 개정

목표: 영문 원문을 보존하면서 한국어로 위치·의미·근거·수정 방향을 설명하고, 위치에 붙일 짧은 검토 코멘트를 제공한다. 한국어로 작성된 완결된 초안 절은 번역 오류로 취급하지 않는다.

1. 운영 파일과 로컬 소스, 통합 QA MD를 읽고 내용 차이와 실행 중인 작업을 확인한다.
2. REQ-MANUAL-023과 공통 보고서의 선택 입력 계약을 정의한다. 기존 호출·열 위치·ID·원문·쪽수 계약을 유지한다.
3. 실제 보고서 생성·MCP 호출의 회귀 시험을 먼저 작성하고 실패를 확인한 뒤 구현한다.
4. 통합 QA MD의 검토·문체·한국어 초안 기준, 연결용 Skill과 관련 문서를 갱신한다.
5. 관련 시험과 준비 검사를 수행하고 변경 파일만 백업·배포한다. 지식은 기존 차등 업로드로 반영한다.
6. 운영 서버의 보고서 출력, 기존 연결의 최신 지침 조회, 파일 해시를 확인하고 커밋·푸시한다.

영향: 기존 연결은 선택 필드가 없어도 계속 동작한다. 새로운 한국어 해설·근거 인용·짧은 메모는 입력한 경우 표시하며 함수가 번역이나 근거를 생성하지 않는다. 기존 Excel A:N 열은 유지한다. 새 도구 목록이 캐시된 대화는 연결 갱신이 필요할 수 있다. 별도 서비스·인증·설정·제품 자료는 변경하지 않는다.
