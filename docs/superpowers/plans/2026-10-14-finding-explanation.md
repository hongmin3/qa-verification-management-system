# 분석 결과를 읽고 이해되게 고치기

작성 2026-10-14. 사용자 요청: "이슈별로 무슨 말인지 전혀 이해가 안 된다. 어떤 분석을 했는지 자세히 적어 달라."
2026-10-14 사용자가 권장안으로 진행하도록 요청했다. 0~3단계(상세 화면·새 댓글 입력·쓰기 규칙)를 먼저 적용한다. 다른 분석 종류의 쓰기 규칙 확대(4단계)는 후속으로 둔다. 같은 날의 `NFR-OPS-003`(브라우저 시험 headless 기본) 커밋도 포함했다. 이후 사용자 지시로 이 작업은 관련 검증·커밋·push까지 수행하고, master 병합·최종 전체 검증·운영 배포는 별도 통합 작업에 넘긴다.

## 1. 지금 무엇이 문제인가 (VP-7237 실제 결과로 확인)

운영 DB의 결과(실행 `20261014-073000-vxvue`, 결과 번호 280)를 읽기 전용으로 확인했다.

| 화면에 보이는 것 | 실제로 저장된 것 | 왜 이해가 안 되나 |
|---|---|---|
| `판정 사양 주장` | `SPEC_CLAIM` = 댓글 작성자가 "사양이 이렇다"고 주장함(SPEC 분류표의 "사양이라는 주장") | 누구의 주장인지, QA 가 확인한 사양인지 알 수 없다 |
| `신뢰도 Review Needed` | 영어 원값 | 뜻을 풀어 주지 않는다 |
| 요약 한 문장 | "…문구가 제시됐고, VP-580 에 … 명시했다고 한다" | 누가 말했는지와 이슈 내용(무엇이 문제였는지)이 없다 |
| 근거 `VXvue/VP-7237/1` | Polarion 댓글 번호 | 파일 경로처럼 보이고 댓글 원문이 없다 |
| (안 보임) | "VP-580 본문은 입력에 없어 SRS 반영 내용은 확인하지 못함" (`detail`) | 가장 중요한 사실(사양과 대조하지 못함)이 `자세히` 안에 묻혀 있다 |
| (안 보임) | 댓글별 해석: 1번 "기대 문구를 3가지 경우로 나눔", 2번 "VP-580 이 바뀌었을 수 있음" | `자세히` 를 열어야 보이고 영어 분류 코드와 섞여 있다 |
| (안 보임) | 새 댓글 원문·작성 시각 (변경 이벤트 #95 에 저장됨) | 상세 화면이 이미 이벤트를 받지만 번호·필드 이름만 그린다 |

원인은 세 가지다.

1. **입력 부족**: 새 댓글 분석(`COMMENT`)은 사양 후보를 받지 않는다(`app/modules/daily_qa/intelligence.py:394-399`). 그래서 연결된 VP-580 을 읽지 못하고 "사양 주장"만 전한다. 댓글 작성자는 수집 단계(`product_adapter.normalize_comment`)에서 버려진다.
2. **쓰기 규칙 부족**: 요약은 "결론부터 한두 문장"만 정해져 있다. 주어·이슈 내용·확인하지 못한 것을 쓰라는 규칙이 없다.
3. **화면**: 영어 코드(`SPEC_CLAIM`, `Review Needed`, `RESOLUTION_INFORMATION`)를 그대로 보이고, 원문과 "확인하지 못한 것"을 맨 위에 두지 않는다.

> **SPEC / CODE MISMATCH** REQ-QAINTEL-015 입력에 "그 이슈의 가장 최근 분석 요약"이 있으나 코드는 넣지 않는다. 이 계획의 2단계에서 코드를 사양에 맞춘다(사양 유지).

## 2. 바꾼 뒤 모습 (VP-7237 예시)

**대시보드 카드**는 지금처럼 짧게 둔다(2026-10-02 "핵심만" 결정 유지). 대신 요약 한 문장이 혼자 읽혀야 한다.

> 검토 필요 · 새 댓글 2건
> [VP-7237] Normal 및 Reject 전송 서버 모두 미설정: No stroage information
> 10-12 댓글에서 "서버 미설정 문구를 영상 종류별 3가지로 나눈다"는 답과 "사양 VP-580 을 고쳤다"는 말이 나왔습니다. AI 는 VP-580 최신 본문과 아직 대조하지 못했습니다.
> QA 할 일 1~3줄

**상세 화면 맨 위**에 "이 분석이 한 일" 다섯 줄을 둔다.

| 칸 | VP-7237 예시 |
|---|---|
| 이슈 | Normal·Reject 전송 서버를 둘 다 설정하지 않으면 `No stroage information`(철자 오류 포함) 이 뜬다 |
| 새로 생긴 일 | 10-12 13:24·13:59 댓글 2건, 작성자 ID (원문 펼치기) |
| 댓글 해석 | 1) 기대 문구 3가지 제안 → 기대 결과 후보, 사양 확인 전 · 2) VP-580 을 고쳤다 → 사양이 바뀌었을 수 있음 |
| AI 가 확인한 것 / 못 한 것 | 확인: 이슈 본문, 새 댓글 2건 · 못 함: VP-580 본문(입력에 없음) |
| 판단과 이유 | 검토 필요: 댓글 설명만 있고 사양 원문으로 확인되지 않았다 |

영어 코드는 한국어로 바꾸고, 원래 코드는 마우스를 올리면 보인다. 예: `Review Needed` → `확인 필요`, 근거 `VXvue/VP-7237/1` → `댓글 1 (10-12 13:24)`.
