# 스킬 배포와 사용자 안내

스킬 배포본을 추가하거나 업데이트할 때 사용자 안내도 함께 갱신한다.

- 안내 위치는 `app/web/static/skills/<스킬 ID>/index.html`, 변경·개선 문서는 같은 하위의 `updates.html`이다.
- 목록은 실제 상세 안내로 바로 연결한다. 기존 VXvue `/vxvue-desktop`과 ALM `/static/alm-ai/index.html`은 그대로 사용하고, skills 하위 index를 링크만 둔 중간 화면으로 만들지 않는다.
- 신규 배포 파일은 서버의 `/static/skills/<스킬 ID>/releases/<버전>/` 아래에 보존하고 상세에서 연결한다. 기존 설치 API와 자료 경로는 호환성을 유지한다.
- 업데이트 날짜·실제 변경·설치 영향·검증 범위와 미검증을 같은 변경으로 기록한다. 파일 감시와 자동 배포가 구현됐다고 표시하지 않는다.
- 해당 페이지 폴더의 `AGENTS.md`를 읽고 관련 안내 시험과 실제 서버 링크를 확인한다. 비밀값·사내 원본 자료는 Git에 넣지 않는다.
- 다른 세션에서 만들고 있는 Bellalun 등 스킬의 파일은 덮어쓰지 않는다. 확정된 배포 경로와 검증 결과를 받은 뒤 안내에 반영한다.
